最終更新日：2026-10-27

取得する情報

本アプリは、Google の OAuth 認証を通じて利用者本人が許可した場合に限り、Gmail API 経由で利用者本人のメールデータ（件名、送信者、本文など、許可されたスコープの範囲内の情報）にアクセスします。あわせて、認証を維持するためのリフレッシュ トークンを取得します。

利用目的

取得した情報は、利用者本人にメール内容を表示・処理する目的でのみ使用します。広告、マーケティング、第三者への販売・提供には使用しません。

保管と共有

  • メールデータおよび認証トークンは、利用者本人の端末／環境内にのみ保管し、外部サーバーへ送信しません
  • 法令に基づく場合を除き、第三者に共有しません

アクセスの取り消しと削除

利用者は、Google アカウントの「サードパーティ製アプリとサービス」の設定から、本アプリへのアクセスをいつでも取り消すことができます。取り消し後、保管していたトークンおよびデータは削除します。

Google API サービス ユーザーデータ ポリシーへの準拠

本アプリによる Google API から取得した情報の使用および他アプリへの転送は、制限付き使用（Limited Use）の要件を含む Google API サービス ユーザーデータ ポリシーに準拠します。
